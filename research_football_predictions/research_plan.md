# Research Plan: APIs, Librerías y Datasets para Predicción de Fútbol

## Pregunta principal
¿Qué fuentes de datos, librerías open-source y datasets gratuitos existen para construir un sistema de predicción de fútbol, cuáles son sus costos, límites y aspectos legales?

## Subtopic 1: APIs de datos de fútbol
Investigar football-data.org, APIFootball (API-FOOTBALL), Sportmonks, Understat, TheSportsDB, OpenLigaDB, Sofascore. Cubrir: datos disponibles, precios, rate limits, calidad.

## Subtopic 2: Librerías Python open-source
Investigar soccerdata, football-data, betfairlightweight, mplsoccer, scrapy/selenium. Cubrir: qué fuentes scrapean, funcionalidades, dependencias.

## Subtopic 3: Datasets gratuitos
Investigar Kaggle datasets populares (European Soccer Database, etc.), GitHub repos con datos históricos, CSV datasets públicos.

## Subtopic 4: Aspectos legales
Investigar términos de uso de las APIs, legalidad del scraping, atribución requerida para cada fuente.

## Síntesis
Combinar hallazgos en un documento markdown organizado con URLs y comparativas.
